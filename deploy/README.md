# GhostRide Kazakhstan MVP

Это статический MVP сайта/web app для стартапа GhostRide Kazakhstan.

## Где лежит код

- `index.html` - структура сайта и экран приложения.
- `styles.css` - весь дизайн и адаптив.
- `app.js` - интерактив: фильтры, карта, выбор авто, регистрация, проверка документов, брони, demo-оплата, депозиты, штрафы, отзывы, календарь владельца и админка.
- `config.js` - настройки backend. Если Supabase URL и anon key пустые, сайт работает как local demo.
- `supabase/schema.sql` - SQL для создания таблиц backend.

## Страницы

- `index.html` - главная страница.
- `cars.html` - каталог авто с картой.
- `car-details.html` - подробная страница машины.
- `how.html` - как арендовать, регистрация, проверка, поездка, завершение.
- `tariffs.html` - тарифы, депозиты, сервисный сбор и штрафы.
- `checkout.html` - demo-бронирование и оплата.
- `owners.html` - добавление своей машины.
- `business.html` - корпоративный доступ и заявки для компаний.
- `faq.html` - вопрос-ответ.
- `rules.html` - правила, зоны, страховка, заправка и ответственность.
- `promo.html` - промокоды, рефералы и бонусы.
- `dashboard.html` - личный кабинет, документы, календарь, Trust Score, выплаты.
- `admin.html` - demo-админка для модерации.

## Регистрация и вход

- `Регистрация` открывает создание аккаунта через Google, Apple/iCloud, телефон или email.
- `Войти` открывает отдельную форму входа, где обязательно нужно указать телефон или email.
- В форме входа есть пароль, восстановление, вход через Google и Apple/iCloud.
- Для входа нужно нажать `Отправить код`, затем ввести 6-значный код и подтвердить вход.
- Без Supabase это работает как demo через localStorage.
- С Supabase можно включить Google/Apple OAuth и email/phone OTP в настройках Supabase Auth.

## Языки

В верхней панели есть переключатель `RU / KZ / EN`. Выбранный язык сохраняется в браузере и меняет основные страницы, навигацию, формы регистрации/входа, статусы авто и подписи интерфейса.

## Как запустить

Самый простой вариант:

1. Откройте файл `index.html` в браузере.
2. Если нужно проверить как сайт на сервере, запустите локальный сервер из этой папки:

```bash
python -m http.server 8000
```

Потом откройте:

```text
http://localhost:8000
```

## Куда ставить

Для обычного сайта: загрузите все `.html`, `styles.css` и `app.js` в одну папку на хостинге. Готовый архив для GitHub Pages: `ghostride-multipage-github.zip`.

## Backend через Supabase

1. Создайте проект Supabase.
2. В Supabase откройте `SQL Editor`.
3. Выполните файл `supabase/schema.sql`.
4. В `Project Settings -> API` скопируйте `Project URL` и `anon public key`.
5. Вставьте их в `config.js`.
6. Загрузите обновленные файлы на GitHub Pages.

После этого машины, регистрации, брони, отзывы, статусы, штрафы и проверки будут храниться в общей базе Supabase, а не только в браузере.

Не вставляйте `service_role` key в `config.js`. Он секретный и не должен быть в frontend.

Для Google и Apple/iCloud входа включите провайдеры в Supabase: `Authentication -> Providers -> Google` и `Apple`. В `Authentication -> URL Configuration` добавьте адрес сайта в `Site URL` и `Redirect URLs`, например:

```text
https://eralitlekkabyl-rgb.github.io/ghostride/
```

Для Telegram Mini App:

1. Загрузите эти файлы на HTTPS-хостинг, например Vercel, Netlify, Timeweb, Beget или свой VPS.
2. Получите ссылку вида `https://your-domain.kz`.
3. В BotFather укажите эту ссылку как Web App URL для кнопки Telegram Mini App.

## Что заменить перед реальным запуском

- Подключить реальную карту: 2GIS, Yandex Maps или Google Maps.
- Подключить оплату: Kaspi, CloudPayments, Stripe или локальный эквайринг.
- Подключить backend: пользователи, документы, машины, бронирования, платежи.
- Подключить телематику/GPS и удаленное открытие авто.
- Добавить страховой сценарий и юридические оферты.
- Перенести localStorage-данные в общую базу данных, чтобы все пользователи видели одни и те же машины, брони и статусы.
